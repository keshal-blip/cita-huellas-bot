# Cita de huellas

Личный Telegram-бот для записи на **toma de huellas** (отпечатки для карты TIE после резиденции) на сайте полиции:

https://icp.administracionelectronica.gob.es/icpplus/index.html

Бот один раз спрашивает провинцию, комиссарию, документ, имя, гражданство, год рождения, телефон и почту. Дальше сам заполняет форму и проверяет места. В процессе пишет только если появилась капча.

## Запуск

1. В Telegram открой `@BotFather`, команда `/newbot`, скопируй токен.
2. Скопируй `.env.example` в `.env` и вставь токен.
3. Установи зависимости и запусти:

```
python -m pip install -r requirements.txt
python bot.py
```

Либо дважды щёлкни `run.bat`.

Бот работает на этом компьютере в фоне. На телефоне ничего не открывается, только сообщения в Telegram. `HEADLESS=1` оставь как есть.

## Команды

- `/start` — запросить данные или продолжить поиск
- `/stop` — остановить
- `/status` — что сохранено
- `/forget` — стереть данные и спросить заново
- `/interval 3` — пауза между проверками, минимум 2 минуты

Когда бот присылает капчу, ответь символами с картинки. Если дата не подходит, напиши `мимо`.

Данные лежат только в `data/profile.json` на этом компьютере.
